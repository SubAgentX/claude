## Project scaffold

The generic project scaffold that used to live in `project-template/` has moved
to its own repository, so there is a single source of truth:

**https://github.com/SubAgentX/project-template**

It is a GitHub template repository — use the **Use this template** button, or:

```bash
gh repo create my-app --template SubAgentX/project-template --private --clone
cd my-app && ./scripts/init.sh "My App" "SubAgentX/my-app"
```
